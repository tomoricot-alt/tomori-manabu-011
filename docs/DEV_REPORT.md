# 開発レポート：TOMORI MANABU (APP 011)

作成日: 2026-10-12 / 状態: 無料MVP（PR作成まで。未マージ・未公開）

## 実装内容
- 画面: ホーム / 撮影・画像選択 / 読み取り中 / 問題の確認 / 学習 / 学習終了
- 写真: カメラ(`capture="environment"`)・写真ライブラリ選択・プレビュー・撮り直し。長辺1600pxに縮小、30MB超は拒否。カメラが使えない場合の代替（ライブラリ選択・手入力）
- OCR: Tesseract.js 7.0.0（固定）をブラウザ内で実行。Worker/WASM/英語言語データは `public/ocr/`（`prepare:ocr` で固定バージョンのnpmパッケージからコピー）から同一オリジン配信。60秒でタイムアウトし、失敗しても手入力へ。写真は学習開始時・終了時・撮り直し時・ホームへ戻る時に破棄
- 問題抽出: 全角/半角・記号ゆれ(`x X * ✕`→×、`/ :`→÷、各種マイナス)を正規化。非負整数の四則とあまりのないわり算のみ。0でわる・あまり・マイナス・5桁以上は「使えない問題」として理由つきで除外（自動採点しない）
- 確認: 問題の編集・追加・削除、最大5問、OCR由来の問題は保護者が「写真とくらべて確認した」にチェックするまで開始不可
- 学習: 1問ずつ大きく表示、ヒント最大3段階（ルールベース、答えの数字を含めない安全装置つき）、数字キーパッド(`inputmode=numeric`)で回答、正誤判定、やさしい声かけ、途中終了
- 音声: SpeechSynthesis(ja-JP)。操作を起点に再生、再生前に`cancel`して重複防止、`pagehide`/非表示/終了時に停止、「もういちど きく」、非対応端末では文字表示のみ
- 保存: `localStorage` に回数・問題数・最終日のみ。削除ボタンあり。利用不可でも動作継続。アプリ内とUSER_GUIDEにサイトデータ削除で消えることを明記
- 外部通信対策: CSP(meta)で同一オリジン以外への接続を禁止。CDN・外部フォント・分析・広告なし
- CI/公開: `.github/workflows/deploy.yml`（npm ci → app-info検証 → 型チェック → テスト → ビルド。公開は main への push のみ）
- APP LAB連携: `app-info.json`（PR #2 の検証ロジックを `scripts/` に複製して検証）

## 既知の制約（未解決）
- **OCRは「÷」を「＋」などに読み違える**（英語モデルで確認。日本語モデルも改善せず）。対策として、OCR結果は必ず保護者が写真と見くらべて確認する仕様にした。自動で確定はしない
- OCRの精度は撮影条件（明るさ・傾き・手書き）に依存。手書きの問題、筆算形式、縦書き、文章題には未対応
- 英語言語データのみ同梱（数字・記号の読み取り用）
- 音声の自然さ・利用可否は端末依存。保証しない
- 初回のOCRは約14MBの資材を読み込むため、回線によって時間がかかる（2回目以降はブラウザキャッシュ次第）
- オフライン動作（Service Worker）は未実装

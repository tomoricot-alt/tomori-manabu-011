# TOMORI MANABU の使い方

小学3・4年生のお子さんが、紙の宿題（算数の計算）に自分で取り組むのを、声かけとヒントで応援するアプリです。
パソコンの知識は必要ありません。iPhoneのSafariで開いてください。

アプリのページ: https://tomoricot-alt.github.io/tomori-manabu-011/

## 1. はじめる前に
- 紙の宿題と、えんぴつ・ノートを用意します。
- スマホは机の上に置きます。音が出るように、マナーモードを切って音量を上げてください（音が出なくても、文字だけで使えます）。
- 名前や学校名などを入力する必要はありません。ログインもありません。

## 2. まずは「おためしで あそぶ」
写真なしで、サンプルの4問で練習できます。使い方に慣れるのにおすすめです。

## 3. 宿題の問題を入れる
1. ホームで「しゅくだいを とる」を押します。
2. 「カメラで とる」で宿題を撮影します。すでに撮った写真は「しゃしんから えらぶ」で選べます。
   - 問題が大きく写るように、明るいところで撮りましょう。
   - うまく写らなかったら「とりなおす」を押します。
   - カメラが開かないときは、「しゃしんから えらぶ」か「てで いれる」を使ってください。
3. 「もんだいを よみとる」を押して、少し待ちます（初回は時間がかかることがあります）。
4. **読み取り結果を、写真と見くらべて確認してください。** 読み取りは間違えることがあります。
   - 特に「÷（わり算）」が「＋」に読まれやすいです。
   - 数字や記号は、画面で直せます。いらない問題は「この もんだいを けす」で消せます。
   - 読み取れなかったときは「もんだいを ふやす」で、手で入れられます。
   - 1回に取り組めるのは **5問まで** です。
5. すべての問題に「しゃしんと くらべて かくにんした」にチェックを入れると、「いっしょに はじめる」が押せます。

対応している問題は、たし算・ひき算・かけ算と、あまりの出ないわり算です（数は4けたまで）。
それ以外（あまりのあるわり算、答えがマイナスになるひき算、0でわる計算など）は、自動では使いません。

## 4. いっしょに やってみる
- 画面には、問題が1問だけ大きく出ます。お子さんは、紙の宿題に答えを書きます。
- 「ヒントを きく」: ヒントが3段階まで出ます。答えはすぐには教えません。
- 「こたえを いれる」: 数字を入れて「たしかめる」を押すと、合っているか確かめられます。間違えても責めずに、もういちど考えられるよう声をかけます。
- 「もういちど きく」: いまの声かけをもういちど読み上げます。
- 「つぎの もんだい」: 次の問題に進みます。
- 「きょうは ここまで」: いつでも終えられます。取り組んだことを認めるメッセージが出ます。

おうちの方へ: 答えを先に教えず、「どう考えたの？」と聞いてあげると効果的です。点数や時間で競わせない作りになっています。

## 5. 大事なこと（記録と写真について）
- **写真は外部に送りません。** 文字の読み取りは、お使いのスマホの中だけで行います。写真は学習を始めたときに破棄されます。
- 問題の内容や名前は保存しません。保存するのは **学習した回数・取り組んだ問題数・最後に学習した日** だけです。
- この記録は、**このスマホのブラウザの中だけ** に保存されます。**ブラウザの「サイトデータ」や「履歴とWebサイトデータ」を消すと、記録は消えます。** 別の端末やほかのブラウザには引き継がれません。
- 記録を自分で消すには、ホームの「これまでの きろく」にある「きろくを けす」を押します。
- シークレットモード（プライベートブラウズ）などでは、記録が残らないことがあります。学習自体はできます。
- ページを開くときには、ふつうのウェブサイトと同じように、ページを配信するサーバー（GitHub Pages）への通信が発生します。

## 6. こまったときは
| こまりごと | 対処 |
|---|---|
| 音が出ない | マナーモードを切り、音量を上げてください。端末の音声が使えない場合は、文字を見ながら進められます |
| 読み取りができない・時間がかかる | 「てで いれる」で、問題を手で入れて始められます |
| 写真が大きすぎると言われた | 画質を下げて撮るか、「てで いれる」を使ってください |
| 記録が消えた | ブラウザのサイトデータを消すと、記録は消えます |
